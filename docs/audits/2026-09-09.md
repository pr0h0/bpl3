# Follow-up audit and CI repair — 2026-09-09

All nine confirmed findings from this follow-up audit, BUG-239 through BUG-247,
have been fixed and committed individually. This records the completed scope;
it does not claim that the language has no remaining bugs.

## CI failure

[GitHub Actions run 34345008118](https://github.com/pr0h0/bpl3/actions/runs/34345008118)
failed three clean-command tests in the Ubuntu system clang release job.
The adjacent check/lint JSON no-input test passed. The first failing assertion
was the symlinked working-directory check in CLIJsonParseability.test.ts.

The runner used Bun 1.4.2; the development machine used Bun 1.3.14. Repeating the
test with Bun 1.4.2 reproduced the expected-exit-1/actual-exit-0 failure. Bun
1.4.2 canonicalizes process.cwd(), losing the logical path supplied by --cwd.
Clean now also checks shell PWD and runtime --cwd paths after verifying that
they resolve to the actual current directory.

The three affected CLI files, including eight new directory regressions,
pass all 245 tests on both Bun versions. The primary repair is commit
828757b8, with a lint-only follow-up in 728f32fc.
