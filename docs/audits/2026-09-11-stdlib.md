# Standard library additions and fixes — 2026-09-11

This batch adds two modules and fixes three runtime/compiler defects. Each item
is committed separately, with executable examples and regression coverage.

## Additions

- [`std/deque.bpl`](../../lib/deque.bpl): a generic double-ended queue backed by
  a circular buffer. It provides front/back insertion and removal, checked
  indexing, reserve, shallow cloning, and iteration. Both ends have amortized
  O(1) insertion/removal. See the [collections guide](../30-stdlib-collections.md).
- [`std/binary.bpl`](../../lib/binary.bpl): non-owning `ByteReader` and `ByteWriter`
  cursors for little- and big-endian unsigned integers. They support standard
  integer sizes and arbitrary widths from one through eight bytes. Failed
  operations leave the cursor and destination unchanged. See the
  [binary guide](../61-stdlib-binary.md).

Both modules are re-exported from `std`. The examples are
[`stdlib_deque`](../../examples/stdlib_deque/main.bpl) and
[`stdlib_binary`](../../examples/stdlib_binary/main.bpl).

## Fixes

- BUG-263: destroying a nonempty queue left stale counts and indices. Destruction
  now resets the queue; negative initial capacities normalize to zero.
- BUG-264: empty Hex/Base64 results were string literals despite a caller-owned
  allocation contract. Freeing them aborted the process. Empty results now use
  allocated NUL-terminated buffers, and the API reference names `decodeToString`
  correctly.
- BUG-265: hexadecimal e/E digits were mistaken for floating-point notation.
  This rounded large integer constants, including `0xfedcba9876543210`, before
  binary encoding. Hexadecimal literals now retain their integer type and bits.

Details and reproductions are recorded in [BUGS.md](../../BUGS.md).

## Validation

Local validation uses Bun 1.4.2 and Clang 21.1.8 on Linux. New runtime regressions
compare O0 and O3 execution and verify LLVM IR. Deque tests compare a deterministic
sequence of mixed operations against a JavaScript array model. Binary tests
compare output against independently calculated byte layouts, including
unaligned buffers, high-bit 64-bit values, truncation, overflow, and invalid seeks.

- TypeScript typecheck, ESLint, and formatting checks: passed.
- Seven new regression tests: passed at O0/O3 with LLVM verification.
- CI-safe integration/playground suite: 572 passed.
- VS Code extension suite: 236 passed.
- Generated CLI registry check: passed.
- Final CI-safe unit phase: 3,278 passed, zero failures across 262 files.
  Its 16 skipped entries are opt-in Docker tests; Docker was not rerun for this batch.
- Documentation and example-convention checks: 96 passed after correcting a
  documentation anchor and canonical C imports in the new examples.
- Additional ASan/UBSan stress checks: passed at O0 and O3 for wrapped deque
  growth/cloning, empty encoding-result frees, and binary cursor boundaries.
  The shared sanitizer harness disables leak detection.

Deque elements are shallow copies; callers retain ownership of element resources.
Binary cursors borrow their buffers, which must remain valid and appropriately
sized for their lifetime. Docker playground users must rebuild the worker image
and restart the controller to pick up these library/compiler changes.
