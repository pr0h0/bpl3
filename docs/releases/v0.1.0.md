# BPL v0.1.0

First public development release of BPL, a statically typed language targeting
LLVM. This release establishes the `0.1.x` series; the compiler and APIs are
still being stabilized.

Included:

- Compiler, standard library, CLI tooling and documentation.
- C ABI interoperability for calling native functions and exporting BPL functions.
- Web packages for HTTP/HTTPS, routing, middleware, authentication and persistence.
- Separate compiler and playground Docker images, published by the version-tag
  workflow after its container tests pass.

## Try the compiler

After the image publication workflow finishes:

```sh
docker run --rm -v "$PWD:/work" -w /work \
  ghcr.io/pr0h0/bpl3-compiler:0.1.0 build main.bpl -o main
```

Exported binaries require a compatible Linux host and runtime libraries. See the
[Docker guide](https://github.com/pr0h0/bpl3/blob/v0.1.0/docker/README.md) for running
programs inside the container and starting the playground. The playground image
is `ghcr.io/pr0h0/bpl3-playground:0.1.0`.

## Validation and limitations

Publication is gated on the requested
[Compiler Correctness run](https://github.com/pr0h0/bpl3/actions/runs/38932160293),
plus release packaging checks for the `0.1.0` metadata.

This is an early development release, not a guarantee of bug-free or memory-safe
programs. Manual ownership and native interoperability require care, and
remaining compiler/library issues are still being addressed. Future releases
remain maintainer-controlled patch versions in the `0.1.x` series.
