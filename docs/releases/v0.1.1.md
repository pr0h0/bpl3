# BPL v0.1.1

A maintenance and developer-experience release covering the tested staging
baseline through PR #85, together with the release packaging corrections in
PR #87. This combined release supersedes the initial 0.1.1 publication.

## Highlights

- Compiler correctness across type/generic validation, const receivers, return
  paths, arrays/tuples/matches, ownership checks and type queries.
- Formatter comment preservation, expression boundaries, stable repeated
  formatting, source coordinates and shared project configuration.
- Package-lock integrity, dependency reconciliation, package entry verification
  and reproducible archives.
- Reliable watch/restart behavior, safer cleanup, accurate editor renames,
  refreshed imports, debounced diagnostics and saving before Run.
- Numeric fixes across statistics, complex arithmetic, modulo, ranges and averages;
  improved random generation, argument parsing and rational arithmetic.
- Directory/stdin format/lint, explicit `--project` build/run, safe generated docs,
  public-only API documentation, complete shell options and playground drafts.

- Instantiated generic override validation and derived virtual dispatch through
  generic parent pointers and bound methods, including value-receiver adapters.

## Compatibility notes

Bound methods borrow receiver storage and do not extend its lifetime. Lifecycle
methods retain direct binding; variadic value-receiver bindings remain unsupported.

Existing documentation outputs now require `bpl docs --force` before replacement.
Formatting/linting directory discovery skips dependency/output/hidden paths and
symlinks. Lint warnings still fail by default; `--no-fail-on-warnings` opts out.
Project entry selection is explicit with `--project`. Playground drafts persist
source, stdin and arguments locally to the browser origin; Clear removes the draft
or reports failure. Stricter compiler checks can reject previously accepted invalid
programs. This remains an early 0.1.x development release with manual ownership
and native-interoperability responsibilities.

## Validation

The source baseline passed all configured PR #84 checks at 5981084b, and its
staging merge tree matches that tested head. Release metadata, packaging and
release-PR checks must also pass before this release is published. Audit reports
and private evidence are excluded from release archives.

No npm publication is performed by creating this GitHub release. Version tags
follow the repository's tested container-image publication workflow; image
availability follows that workflow's successful completion.
